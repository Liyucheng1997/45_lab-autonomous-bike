# 自动驾驶自行车 · Three.js 仿真（XUAN 方法复刻）

参考稚晖君（彭志辉）开源项目 **[XUAN](https://github.com/peng-zhihui/XUAN)**，在 Three.js 中
复刻其**自平衡 / 自动驾驶方法**，并尽量保证物理（尤其是平衡动力学）与真实一致。不做 3D 打印，纯仿真。

## 快速开始

```bash
npm install
npm run dev      # 打开终端里给出的 http://localhost:5173
```

> 注意：必须在**可见的浏览器窗口**中运行。无头/后台标签页会被浏览器暂停
> `requestAnimationFrame`，物理循环不推进（画面看起来卡住）。

构建：`npm run build`，预览构建产物：`npm run preview`。

## 它复刻了 XUAN 的什么

| XUAN 真实硬件/方法 | 本仿真中的实现 |
| --- | --- |
| 动量轮（reaction wheel）静止平衡 | 反作用轮倒立摆 + **LQR** 状态反馈 (`lqr.js`) |
| 转向舵机：行驶平衡 + 转弯 | 转向平衡辅助 + 纯追踪路径跟踪 (`controller.js`) |
| 后轮驱动电机 | 一阶速度环 |
| MPU6050 IMU 测倾角 | 直接读取仿真状态 θ, θ̇ |
| LQR 反馈矩阵 + ~50 参数 | 在线求解的反馈增益 K + GUI 可调参数 |

## 物理模型（真实动力学，非玩具）

把车身当作绕轮触地线的**倒立摆**，状态量 `θ, θ̇, Ω(动量轮转速), ψ(航向), x, y, v, δ(转向)`：

- 横滚：`Ip·θ̈ = m·g·l·sinθ − u_wheel + τ_steer`
- 动量轮：`Iw·Ω̇ = u_wheel`
- 转向回正力矩：`τ_steer = −m·h·(v²/b)·tanδ·cosθ`
- 航向/位置：自行车运动学 `ψ̇ = (v/b)tanδ`，`ẋ=v cosψ`，`ẏ=v sinψ`
- 积分：固定步长 **RK4**（`physics.js`）

控制（`controller.js`）：
- 动量轮 `u = −K·[θ, θ̇, Ω]`，K 由离散 Riccati 迭代在线求解（`lqr.js`），等价于连续 LQR。
- 转向 `δ` = 高速平衡辅助(θ,θ̇) + 航点纯追踪，随速度淡入。
- 力矩/转速/转角均有物理饱和限制。

### 物理真实性的体现
关键约束：**动量轮力矩必须大于峰值重力力矩 `m·g·l·sinθ` 才能回正**，否则大角度必倒——
这正是真实反作用轮系统的固有限制。经离线仿真验证：

- 静止：动量轮可从约 ±1.5 rad/s 的横向冲击中回正。
- 行驶（如 3 m/s）：转向介入后可承受更大冲击（动量轮 + 转向混合控制）。
- 可连续跑完 8 字路径多圈不倒，过弯自然侧倾约 15–18°。

## 操作

- 鼠标拖动旋转视角，滚轮缩放。
- **空格**：施加一次横向冲击扰动（看它如何回正）。
- **R**：复位。
- 右上面板：目标速度、LQR 权重 Q/R、转向增益、物理参数（质量/质心高/惯量等，改后自动重算 LQR）。
- 面板里 “走 8 字路径” 演示自动驾驶路径跟踪。

## 文件结构

```
src/
  params.js      物理参数（XUAN 量级，UI 实时可调）
  lqr.js         矩阵运算 + 离散 Riccati LQR 求解
  physics.js     动力学方程 + RK4 积分 + 线性化模型
  controller.js  LQR 平衡 + 转向平衡辅助 + 纯追踪路径跟踪 + 速度环
  bike.js        参数化三维车模型（车架/双轮/转向/动量轮）
  ui.js          lil-gui 控制面板
  main.js        场景/光照/地面/相机/渲染循环/HUD/示波器/交互
```

## 关于导入 XUAN 的原始模型

XUAN 仓库只提供 Fusion360 / STEP 格式 CAD（作者注明 STL 导出有 bug），而 Three.js 无法直接加载
STEP。因此本项目默认用**参数化车模型**还原 XUAN 的构型。若你把 CAD 转换成 `glTF/.glb`
（例如用 Blender 或 FreeCAD 导入 STEP 再导出 glb），可直接挂载：

```js
await bike.loadExternal('/models/xuan.glb'); // 见 bike.js，可能需手动调整缩放/朝向对齐
```

## 已知限制

- 平面（pitch/横向滑移）等高阶自行车动力学（如 Whipple 模型的陀螺效应）做了简化，
  聚焦于 XUAN 核心的“反作用轮 + 转向”平衡，保证可控且物理直观。
- 真实可恢复的扰动范围受动量轮力矩/转速上限约束，可在 GUI 中调大电机参数以增强鲁棒性。
