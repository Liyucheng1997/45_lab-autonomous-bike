# XUAN-AV · 自动驾驶自行车数字孪生（v1.1）

受稚晖君 **[XUAN](https://github.com/peng-zhihui/XUAN)** 启发，用 Three.js 做的一辆“真正的”自动驾驶自行车：
**硬件**按真实部件建模、**动力学**用经过论文验证的自行车模型、**软件**走完整的感知 → 规划 → 控制链路。
全部程序化生成，零外部模型/贴图资源。

```bash
npm install
npm run dev     # 浏览器打开终端里给出的地址
npm test        # 动力学 / 控制 / 自动驾驶回归测试（node，无需浏览器）
npm run build
```

> 页面须在**可见**的浏览器窗口里运行；后台标签页会暂停 `requestAnimationFrame`，仿真随之暂停。

## 一、硬件：三维模型 = 动力学模型

车架几何（轴距、拖曳距、头管角、后下叉长……）在 `core/geometry.js` 里由少数设计参数推导，
**三维模型和动力学共用这一份几何**。每个部件的质量、安装位置、形状列在 `core/hardware.js` 的 BOM 里，
程序据此求出 Whipple 模型四个刚体的质量、质心和惯量张量 —— 在面板里加重飞轮、改头管角，
模型外观和车辆动力学会**同时**改变。

| 子系统 | 建模内容 | 规格（默认） |
| --- | --- | --- |
| 车架 | 变截面椭圆扫掠管：内置电池的加粗下管、锥形头管、S 弯后下叉、勾片、碗组 | 27.5″，轴距 1.04 m，头管角 71°，拖曳距 68 mm |
| 车轮 | 胎面花纹 + 棕色胎侧外胎、箱形截面轮圈、**交叉编法辐条**（前 32 根 3 交叉 / 后 36 根 1 交叉）、气门嘴、160 mm 打孔碟片 | 后轮为**轮毂电机**（散热筋 + 霍尔测速），32 N·m / 500 W |
| 传动 | 42T 牙盘、18T 飞轮、**按节距逐节排布的链条**（实例化渲染）、曲柄、带防滑钉的脚踏 | |
| 动量轮 | 抛光钢轮缘 + 镂空腹板飞轮、外转子 BLDC、定子板与四根撑杆、管夹、聚碳酸酯护罩 | Ø280 mm / 2.8 kg，18 N·m，4000 rpm |
| 转向执行器 | 带散热筋的 BLDC + 编码器、15T/45T 同步带轮、**扫掠生成的同步带**（小带轮按 1:3 跟转） | 16 N·m，14-bit 编码器 |
| 传感器 | 16 线 360° 激光雷达（旋转头 + 状态灯环）、RGB-D 深度相机（双目 + RGB + 投射器，抱箍头管）、GNSS RTK 天线 | |
| 计算 / 电气 | 带散热鳍片的计算单元 + 数传天线、MCU/IMU/FOC 驱动盒、急停按钮、电池电量灯、线束（含橙色高压线） | 36 V 468 Wh |

点击 **硬件标注** 看引出线式部件说明；点击 **BOM / 模型** 看完整物料清单、Whipple 矩阵、
裸车特征值随速度的变化和当前 LQR 增益。

## 二、动力学：Whipple–Carvallo 自行车 + 动量轮

`core/whipple.js` 按 Meijaard 等 (2007, *Proc. R. Soc. A*) 附录 A 从物理参数构造

    M q̈ + v·C₁ q̇ + (g·K₀ + v²·K₂) q = f,   q = [φ 横滚, δ 转向]

它包含了真实自行车的关键效应：转向几何（拖曳距、后倾角）、车轮陀螺效应、前轮“甩头”。
**用论文的基准自行车验证：矩阵误差 1e-14，自稳定速度区间 4.293–6.025 m/s（论文 4.292–6.024）。**

在此基础上（`core/plant.js`, `core/physics.js`）：

- 用拉格朗日法把飞轮自转惯量从横滚惯量中分离，飞轮相对转速 Ω 作为独立自由度：
  `M′q̈ + … = [−τ_rw, T_δ]`，`Iw(φ̈ + Ω̇) = τ_rw − b·Ω`
- 非线性：重力项用 sin φ，地面转角 `δg = atan(tan δ·cos λ / cos φ)`，平面运动学无侧滑
- 执行器：动量轮力矩–转速特性（反电动势使可用力矩随转速线性下降）、转向机械限位、
  轮毂电机力矩/功率上限、电子刹车、滚阻 + 风阻
- RK4，步长 2 ms

本车（无骑手，24.6 kg，质心高 0.58 m）的裸车在 **3.95–5.25 m/s 自稳定** —— 和真实无人自行车一样，
不加控制、推着跑也能自己保持平衡一段速度区间。

## 三、软件：从传感器到执行器

```
 激光雷达 10Hz ─┐                         ┌─ 纯追踪 → 曲率 κ ──┐
 RGB-D 检测 10Hz ┼→ 占据栅格 → A* → 平滑 ─┤                    ├→ MotionController 500Hz ─→ 动量轮 / 转向 / 轮毂电机
 高精地图先验 ───┘   (距离场)   速度规划  └─ 行人让行 / 紧急制动 ┘        ↑
                                                                IMU + 编码器 → 互补滤波估计器
```

| 层 | 文件 | 做法 |
| --- | --- | --- |
| 传感器 | `core/estimator.js` | 陀螺（零偏 + 噪声）、加速度计（含向心加速度和 IMU 安装高度带来的切向加速度）、14-bit 转向编码器、动量轮/轮毂电机测速 |
| 状态估计 | `core/estimator.js` | Mahony 式互补滤波 + 零偏积分 + 运动学向心补偿；控制器**看不到真值** |
| 平衡控制 | `core/controller.js` | 状态 `[φ, δ, φ̇, δ̇, Ω]`、输入 `[τ_rw, T_δ]` 的 **2 输入 LQR**，在 −1.5…10 m/s 的 47 个速度点上用 SDA 倍增算法离线求解、运行时插值（增益调度）。低速靠动量轮，速度上来后 LQR 自动把平衡交给转向，并自然产生**反打方向 (countersteer)** |
| 转弯 | `core/plant.js` | 由曲率求稳态转弯的 `[φ_ref, δ_ref]` 与转向力矩前馈（使动量轮稳态出力为 0） |
| 激光雷达 | `core/lidar.js` | 16 线 × 360°，射线随车身横滚倾斜；对盒体/圆柱/树冠解析求交，按方位角分桶加速（与暴力求交逐束一致，1.3 ms/帧） |
| 建图 | `core/mapping.js` | log-odds 占据栅格 0.25 m，射线清除（行人走开后地图会放行），倒角距离变换 |
| 规划 | `core/mapping.js` | 8 邻域 A*（贴近障碍惩罚 + 离开道路惩罚），视线裁剪 + 不进入膨胀区的梯度平滑 |
| 视觉感知 | `core/perception.js` | 相机视场/量程/遮挡内的目标检测 + α-β 跟踪估计速度 |
| 决策 | `core/autopilot.js` | 速度规划（曲率限速、近障限速、减速度约束）、纯追踪、**行人轨迹预测让行**、沿规划路径扫掠车宽的碰撞走廊 → 紧急制动、无路时原地平衡等待 |

## 四、验证（`npm test`）

| 场景 | 结果 |
| --- | --- |
| 静止，侧向冲击 0.35 rad/s | 回正（动量轮力矩打满 18 N·m） |
| 静止，侧向冲击 0.5 rad/s | **倒地** —— 超过动量轮力矩极限，物理上就扶不住 |
| 3.2 m/s 行驶，侧向冲量 12 N·s | 回正，动量轮几乎不出力，转向完成平衡 |
| 稳态转弯 3.2 m/s、R = 8 m | 实际 R = 7.9 m，侧倾 7.5°（理论 atan(v²/gR) = 7.5°） |
| 环线自动巡航 120 s（含 IMU 噪声） | 不倒、零碰撞、绕开车辆/锥桶/护栏/纸箱、为横穿行人停车让行 |

可恢复的侧向冲量随速度显著增大（静止 ≈4 N·s，1.5 m/s ≈8，≥3 m/s >20）：骑过车的人都知道，
骑得越快越稳 —— 这个模型复现了这一点。

## 五、操作

| 操作 | 说明 |
| --- | --- |
| `1` / `2` / `3` / `4` | 原地平衡 / 环线巡航 / 点击导航（再点地面设目标）/ 手动遥控（WASD） |
| `E` | 急停 |
| `Space` | 侧向推一把（力度随车速自动调整） |
| `R` | 复位 |
| `C` 或顶栏按钮 | 相机：追随 / 环绕 / 俯视 / 车载第一视角 |
| `Shift + 点击` | 放一个锥桶，看它被扫描、建图、绕行 |

右上角 **参数 · 调试** 面板可以改 LQR 权重、执行器能力、车架几何、传感器噪声、时间倍率；
关闭 “使用 IMU 估计” 可对比理想传感器。右下角是车载相机画中画和检测框。

## 已知简化

- Whipple 模型是在直立直行附近线性化的；大侧倾角下只对重力项做了非线性修正。
- 轮胎为理想纯滚动（无侧滑、无轮胎力饱和），地面为平面。
- 定位使用真值位姿（未模拟 GNSS/里程计漂移）；视觉检测是行为级模型，不跑真实神经网络。
